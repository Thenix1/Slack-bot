# How to use the bot  
There are 2 methods. Either you can join the hack club slack and u can command him from almost any channel. (He's only visible for you) (https://hackclub.enterprise.slack.com/archives/C0P5NE354)  
Or you can set him up for yourself  

# Commands
/akzret-uhere? - Pings akzret  
/akzret-help - Shows entire palette of Akzret commands  
/akzret-advice - Tells advice, maybe useful one  
/akzret-fox - Sends an image of fox  
/akzret-o/ - Helo

# How to set up for yourself  
1. You need to clone this git. (https://github.com/Thenix1/Slack-bot)  
2. Cd from your terminal into the extracted folder.  
3. Install npm if you haven't already. (https://nodejs.org/en/download)  
4. Create your own .env file insidethe folder which will hold your tokens. (Set them up in the form "SLACK_BOT_TOKEN=your_token", "SLACK_APP_TOKEN=your_token")  
5. If you dont have the tokens you can go to https://api.slack.com/apps to create a new app and set it up to find your tokens and so the slash commands match the ones in the code.  
6. After all these steps u can finally run node index.js in your terminal. (You need to check that the bot will say "Bot is running!" otherwise, it isn't.
